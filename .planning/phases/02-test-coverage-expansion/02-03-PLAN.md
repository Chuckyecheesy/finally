```tsx
interface PanelProps {
  title: string;
  aside?: ReactNode;
  children: ReactNode;

}
export function Panel({ title, aside, children, className, bodyClassName }: PanelProps)
```

Renders a `<section aria-label={title}>` containing an `<h2>` with `title` text, the `aside` slot in the header, and `children` in the body div (which gets `bodyClassName` applied).

From `frontend/src/components/Sparkline.tsx`:
```tsx
interface SparklineProps { points: number[]; width?: number; height?: number; }
export function Sparkline({ points, width = 56, height = 18 }: SparklineProps)
```
With `points.length < 2`: renders an `<svg>` containing a dashed placeholder `<line>` and `opacity-40` class on the `<svg>`. With `points.length >= 2`: renders an `<svg>` containing a `<polyline>`; the `<svg>` has class `text-up` when `points[points.length-1] >= points[0]`, else `text-down`. Both `<svg>` elements have `aria-hidden` (query via `container.querySelector("svg")`, not `getByRole`, since `aria-hidden` removes it from the accessibility tree).

From `frontend/src/components/TradeBar.tsx`:
```tsx
interface TradeBarProps {
  ticker: string | null;
  lastPrice: number | null;
  cash: number;
  onTrade: (ticker: string, quantity: number, side: Side) => void | Promise<unknown>;
  error: string | null;
  onDismissError: () => void;
}
export function TradeBar({ ticker, lastPrice, cash, onTrade, error, onDismissError }: TradeBarProps)
```
Inputs: `aria-label="Ticker"` (text input, defaults to `ticker` prop, uppercased+trimmed on submit), `aria-label="Quantity"` (text input, default value `"1"`). Buttons: text `"Buy"` and `"Sell"`, both `disabled` when the symbol is empty or quantity is not a positive finite number. Clicking Buy/Sell calls `onTrade(symbol.trim().toUpperCase(), quantity, "buy"|"sell")`. When `error` is non-null, renders `role="alert"` containing the error text and a dismiss button `aria-label="Dismiss error"` calling `onDismissError`. Changing the `ticker` prop (via rerender) updates the Ticker input's value.
