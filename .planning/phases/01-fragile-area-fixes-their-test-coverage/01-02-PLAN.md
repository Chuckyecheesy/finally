<objective>
Surface "this position is priced at its own cost basis because we have no market data for it" as an explicit `stale: bool` on the portfolio API, and plumb it through the frontend types so a stale position is distinguishable from a genuine break-even.

Purpose: `build_portfolio` silently substitutes `avg_cost` for a missing cached price, which reports exactly 0.00% unrealized P&L. With Massive configured and a bad/rate-limited key, a whole session can look healthy while being priced on cost basis indefinitely (PLAN.md §5 explicitly forbids falling back to the simulator, so this is a reachable production state).
Output: `PositionOut.stale` on the API contract, set correctly in `build_portfolio`, covered by backend tests, and mirrored in `frontend/src/lib/types.ts` / `api.ts` / `useTerminal.ts` with frontend test coverage.

Scope guard: this is a data/contract change only. Do NOT add any visual "stale" badge, styling, or UI affordance — this milestone is hardening-only and REQUIREMENTS.md § Out of Scope lists "New user-facing features".
</objective>

## Trust Boundaries

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-04 | Information disclosure | `PositionOut.stale` in the API response | accept | The flag reveals only "we have no cached price for a ticker you already own" — no upstream provider identity, no key state, no error text. Single-user, no-auth, local app; the caller already owns every position in the response. |
| T-01-05 | Tampering | Portfolio valuation math | mitigate | `stale` is derived purely from `price_cache.get_price(...) is None`; all money math (`market_value`, `unrealized_pnl`, `unrealized_pnl_percent`) is left byte-identical, and the existing `tests/api/test_portfolio.py` valuation tests act as the regression gate. |
| T-01-06 | Spoofing | Frontend trusting `raw.stale` from the wire | mitigate | `normalizePosition` uses `raw.stale === true`, so any non-`true` value (missing, string, number, null) normalizes to `false` — no injection path into rendering, consistent with the file's existing `num()` coercion discipline. |
| T-01-SC | Tampering | npm/pip/cargo installs | mitigate | No new packages are installed by this plan — no package-manager install task exists here, so the supply-chain surface is unchanged. |
